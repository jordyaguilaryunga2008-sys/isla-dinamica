# 🥝 Isla Dinámica para Windows

Una isla dinámica en la parte de arriba de tu pantalla, con un kiwi que vive adentro.
Se encoge cuando no la usas y se abre con un clic.

## Descargar

👉 **[Descargar el instalador (Windows 10/11, 64 bits)](../../releases/latest)**

En la página que se abre, toca **`IslaDinamica-Setup-1.0.0.exe`**.

### "Windows protegió su PC"

La primera vez, Windows puede mostrar ese aviso porque el instalador todavía no tiene firma digital
(es un certificado pago). Para instalar: toca **Más información → Ejecutar de todas formas**.

## Qué hace

- **Música:** portada, título, barra con olas y la letra de la canción (Spotify, YouTube y más).
  Con la isla cerrada, pon el mouse sobre la portada para pausar o cambiar de canción.
- **Avisos:** los avisos de Windows (WhatsApp, Discord, correo…) aparecen en la isla.
- **Volumen y brillo:** al cambiarlos, la isla muestra una barrita.
- **Tu PC:** CPU, memoria, batería y temperatura, con alertas que tú ajustas.
- **Bandeja:** arrastra archivos a la isla y tenlos a mano.
- **Portapapeles:** lo último que copiaste, para volver a pegarlo.
- **Herramientas:** nota rápida, cronómetro, temporizador, calendario, captura de pantalla,
  calculadora y modo enfoque.
- **El kiwi:** se asoma, baila con la música, se come lo que cae de la isla y se refugia en su
  casita cuando llueve. El cielo cambia con la hora y el clima.
- **Ajustes:** tamaño, tema, pantalla, aura de color y más (clic derecho → Ajustes).

## Privacidad

Todo se guarda solo en tu PC (`%AppData%\IslaDinamica`). La isla no tiene cuentas ni envía tus datos.
Solo se conecta a internet para el clima (Open-Meteo, con tu ubicación aproximada) y para la letra
de las canciones cuando la pides (LRCLIB). Ambas cosas se pueden apagar.

## Desinstalar

Configuración de Windows → Aplicaciones → **Isla Dinámica** → Desinstalar.
